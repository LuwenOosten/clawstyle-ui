# Preview screenshots / 预览截图

All screenshots were captured from the running frontend connected to an isolated Hermes backend. Conversations, model replies and configuration are synthetic. The visible `/tmp/hermes-clawstyle-test` paths belong only to this disposable test environment. No real user conversations, credentials or personal paths are shown. Screenshots have not been altered.

所有截图来自运行中的前端及隔离 Hermes 后端。对话、模型回复与配置均为合成演示数据。图中的 `/tmp/hermes-clawstyle-test` 仅属于临时测试环境，不包含真实对话、凭据或个人路径。截图未做内容修改。

- `config-preview.png`: English General configuration, including model/context/toolsets (1440 × 900).
- `chat-preview.zh-CN.png`: Simplified Chinese navigation with the same synthetic English conversation.
- `mobile-preview.png`: narrow-screen Simplified Chinese chat (390 × 844).

Font binaries were not copied into this repository. This compares font styles and is not a functional screenshot or whole-page upstream before/after comparison.

`typography-comparison.png` 是同内容字体样张：左侧临时读取旧项目 Mondwest/Rules 字体，右侧使用系统无衬线与中文回退。旧字体二进制未复制到本仓库。该图仅比较字体风格，不是功能截图或整页上游对比。
