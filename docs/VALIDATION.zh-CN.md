## 隔离 Hermes 集成

验证后端为上游 commit [`2f80ae0a6a91932b1808a53f9c55f8b3f313d6cc`](https://github.com/NousResearch/hermes-agent/commit/2f80ae0a6a91932b1808a53f9c55f8b3f313d6cc)，Dashboard API 和 gateway 源码未改动。测试使用临时 Hermes home、profile、工作区与独立端口，没有导入真实凭据或会话。模型回复由本地 OpenAI 兼容测试服务生成。

以下流程通过真实 Hermes REST/WebSocket 服务验证：

- 页面认证初始化、创建首条消息、流式回复与完成。
- 延迟流式回复过程中中断，结束状态为 interrupted。
- 断开连接后重连，恢复持久化会话历史。
- 真实工具审批：拒绝后合成测试文件不变；允许一次后只操作临时测试目录。
- 配置保存后回读；独立 profile 的配置不会修改默认 profile。

Hermes 的依赖环境按 `HERMES_HOME` 定位，因此隔离测试启动器复用了已安装的依赖解释器并跳过包管理器环境激活。这仅是测试适配，不是给用户的安装方式；文档使用正常命令 `hermes dashboard --no-open --port 9119`。
